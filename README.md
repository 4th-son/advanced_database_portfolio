# MIT 8103 – Advanced Database Systems

## Project: MarketLink

**Multi-Vendor E-commerce and Inventory Management System**

## Project Overview

MarketLink is a proposed online marketplace designed to support multiple vendors and customers. The system manages product listings, inventory, customer orders, payments and deliveries.

This project demonstrates the practical application of advanced database concepts through database design, query processing, transaction management, NoSQL implementation and distributed cloud database technologies.

## GitHub Repository

[View the MarketLink Advanced Database Portfolio](https://github.com/4th-son/advanced_database_portfolio)

## Technologies Used

- PostgreSQL – Relational database management.
- pgAdmin 4 – PostgreSQL database administration.
- MongoDB Atlas – NoSQL database deployment and document storage.
- Draw.io – Entity Relationship Diagram (ERD) design.
- Git and GitHub – Version control and project documentation.

## Portfolio Activities

### Portfolio 1: Database Design and Modelling

Design and implementation of the MarketLink relational database, including entity relationships, primary keys, foreign keys, constraints and normalisation.

### Portfolio 2: Query Processing and Optimisation

Development of SQL business queries, query execution analysis, indexing and database performance optimisation.

### Portfolio 3: Transactions and Concurrency

Practical exploration of transactions, COMMIT, ROLLBACK, isolation levels and row-level locking.

### Portfolio 4: NoSQL and Advanced Data Models

Implementation of a document-oriented order database using MongoDB Atlas, including document insertion, querying, projection and aggregation exercises.

### Portfolio 5: Distributed and Cloud Databases

Exploration of cloud database deployment, replication, sharding, availability and consistency using MongoDB Atlas.
