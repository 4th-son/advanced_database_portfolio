# MIT 8103 – Advanced Database Systems

## Project: MarketLink

Multi-Vendor E-commerce and Inventory Management System.

## Project Description

MarketLink is a proposed online marketplace designed to
support multiple vendors, customers, product management,
inventory tracking, order processing, payments and deliveries.

## Technologies

- PostgreSQL
- pgAdmin 4
- MongoDB
- Draw.io

## Portfolio Activities

1. Database Design and Modelling
2. Query Processing and Optimisation
3. Transactions and Concurrency
4. NoSQL and Advanced Data Models
5. Distributed and Cloud Databases
